## 3. Finding: 14 was NOT the ceiling — 2 genuine gaps

Three of the user's own root pillars — **MEMORY**, **KNOWLEDGE**, and the
heavily-stressed **ACCESS/GATHER-ANYTHING** — are currently only
branches. Given the user names them as *root-level* pillars, they earn
trunk status. Two new trunks close every gap:

### XV — MEMORY & KNOWLEDGE BASE
**Essence:** the substrate of remembering and knowing — working,
episodic, semantic, and procedural memory unified in the temporal
knowledge graph; consolidation, forgetting, retrieval, and the total
"what it knows" store. *JARVIS's instant recall of everything Tony ever
did.* **Anchored in:** Common Model of Cognition (declarative +
procedural + episodic memory as core modules); Tulving's memory
taxonomy; RAG/knowledge-graph agent-memory surveys. **Bot:** Layer 10's
Graphiti-style graph promoted from "a layer" to a first-class faculty —
every experiment, verdict, reason, and self-model version lives here.
**Why a trunk not a branch:** in every cognitive architecture memory is
the LARGEST subsystem, and the user names it as a root pillar twice.

### XVI — UNIVERSAL ACCESS & ACQUISITION (the "reach anything" faculty)
**Essence:** the single faculty for reaching, ingesting, and integrating
ANY legitimately-reachable information, tool, API, or data source —
internet research, broker/data APIs, filings, news, papers, feeds — plus
writing itself new acquisition tools when a gap recurs. *JARVIS pulling
any fact / operating any system in the workshop instantly.* **Anchored
in:** autonomous-agent tool-use + retrieval literature; open-web agent
research. **Bot:** unifies what were scattered branches (SENSES/internet-
research + BODY/tool-use + data-prospecting) into one omni-reach organ.
**GATED (hard):** "access/bypass anything" = aggressive use of
legitimately-reachable data + beating *technical* friction (rate limits,
formats, flakiness) — it does NOT authorise bypassing authentication,
authorization, paywalls-as-law, or any law, and NEVER market
manipulation (constitutional, §12 G1/G3). Everything routes through the
Constitutional Core, Referee, and power budgets.
