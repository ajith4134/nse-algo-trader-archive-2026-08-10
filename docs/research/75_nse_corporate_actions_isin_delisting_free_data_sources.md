# Free/legitimate sources for NSE corporate-actions history, ISIN/symbol-change records, and delisted-securities master

Research date: 2026-07-25. Method: 4 parallel research sweeps (official exchanges; regulator/depositories/MCA; open-source Python libraries read from source; GitHub/Kaggle dumps + vendor free tiers), each using WebSearch to discover and WebFetch to actually read pages before citing. Access to nseindia.com, bseindia.com, sebi.gov.in, data.gov.in, mca.gov.in, nsdl.co.in, cdslindia.com was heavily bot-blocked from this tool environment (timeouts / 403 / ECONNRESET on most direct fetches); this is reported as a finding, not glossed over. Every claim below is tagged with how it was verified.

Hard filter applied: no credential sharing, no paywall/auth bypass, no ToS-violating scraping is *recommended*. Where a site's own ToS restricts scraping/reuse, that text is reported verbatim/paraphrased so a human can decide — it is not silently excluded, and it is not silently endorsed either.

## (a) Corporate-actions deep history (splits, bonuses, dividends, rights)

Ranked by (freshness of verification × depth × legitimacy):

1. **NSE `corporates-corporateactions` API** — `https://www.nseindia.com/api/corporate-actions?index=equities` (also wrapped as `corporates-corporateactions`). Confirmed to exist and be the endpoint that `nselib` and `nsepython` call (read directly from their source code, verified 2026-07-25: `nselib/capital_market/capital_market_data.py`, `nsepython/rahu.py`). Accepts `from_date`/`to_date`/`period` — an arbitrary historical range query, not just forthcoming actions. **Caveat**: this is a raw filings feed (symbol, subject line, dates) not a typed split/bonus/dividend/rights schema — the type must be parsed out of the free-text "subject." Requires a browser-like session (cookies from an initial nseindia.com page load); direct stateless fetch times out/blocks, consistent across 3 independent fetch attempts today. Free, no login, but NSE's Terms of Use (page exists at `nseindia.com/static/nse-terms-of-use`, could not be fetched directly today after repeated timeouts, but is quoted second-hand by multiple sources) reportedly restricts "systematic or automated data collection activities, including scraping, data mining, data extraction and data harvesting" without authorization — flagged, not resolved, since the primary text couldn't be re-verified today.
2. **BSE `DefaultData/w` corporate-actions API** — `https://api.bseindia.com/BseIndiaAPI/api/DefaultData/w` (confirmed via the actively-maintained `bse` PyPI/GitHub library, `BennyThadikaran/BseIndiaApi`, read from source 2026-07-25). Supports `segment`, `from_date`, `to_date`, `purpose_code` (e.g. `P5` = bonus) — genuinely typed/filterable by action category, which is better-structured than NSE's feed. Free, no login. BSE-listed scrips only.
3. **`nselib` / `nsepython` / `jugaad-data` Python libraries** — wrap #1/#2 above with retries and cookie/header spoofing. All three are actively maintained (last commits within the last ~4 months as of 2026-07-25) and openly licensed (Apache-2.0, GPL-3.0, and a public-domain "YOLO License" respectively — confirmed by reading each repo's LICENSE file). Use these instead of writing a scraper from scratch: `nselib.capital_market.corporate_actions_for_equity()`, `nsepython`'s equivalent, `bse.BSE.actions()`. None guarantee depth beyond what the underlying NSE/BSE endpoint serves (unverified how many years back the endpoint itself retains — sub-agent could not get a clean historical-depth read due to session/bot blocking).
4. **rkTrader/corpActions (GitHub)** — `https://github.com/rkTrader/corpActions` (fetched 2026-07-25). Committed CSV of bonus/split adjustment factors "since Jan 1st 2000," scoped to F&O underlyings only (not the full ~2,000+ stock universe). **No LICENSE file** — legally no explicit reuse right despite being public; usable only as a cross-check/leads source, not a dependency.
5. **Tickertape.in (free tier)** — `https://www.tickertape.in/stocks/<slug>` (fetched 2026-07-25). Free page shows itemized dividends (ex-date+amount), bonus issues, rights issues, and demergers with dates, per-company — richer at-a-glance free corporate-action display than Screener.in. No documented API; ToS (`tickertape.in/meta/terms`, fetched 2026-07-25) explicitly prohibits reproducing/copying/scraping/creating derivative works from the service — this would need to stay manual/UI-only or be treated as a cross-check source, not a bulk feed.
6. **Screener.in (free tier)** — dividend-payout-% history visible free; itemized split/bonus/dividend-with-dates not rendered on the free tier as fetched 2026-07-25. ToS bars copying/modifying/commercial reuse in broad terms (no scraping-specific clause found).
7. **Kaggle "Techsalerator" and "Survivorship-Free Indian Equity" datasets** — both are marketing/lead-gen teasers of paid commercial products (confirmed via dataset pages fetched 2026-07-25): Techsalerator's is 79.8KB "representative sample" with an "Unknown" license badge (full data requires a paid quote); the survivorship-free dataset (CC BY 4.0, updated 2026-06-23) ships only small samples and gates the full ~3,800-name dataset behind opening a GitHub issue. Neither is a usable free bulk corporate-actions history on its own, but the survivorship-free sample is a legitimately licensed cross-check for delisted-name coverage (see (c)).

**Verdict for (a):** No single free source gives a clean, typed, deep-history (10-20yr) corporate-actions table for the full ~2,000+ stock universe. The best achievable free stack is NSE's + BSE's own historical corporate-action query APIs (accessed via the openly-licensed `nselib`/`nsepython`/`bse` libraries), parsed from free-text into typed events, cross-checked against Tickertape's free per-company pages and BSE's typed `purpose_code` filter for validation. Depth is bounded by whatever NSE/BSE's endpoints themselves retain (not independently confirmed to go back further than ~2015-2016 in EOD-report form; the API query range itself is unbounded but unverified how far actual records go).

## (b) ISIN-change / merger / symbol-change records

1. **NSE `symbolchange.csv`** — `https://archives.nseindia.com/content/equities/symbolchange.csv` — **directly fetched and confirmed 2026-07-25**, no login/session required, plain public CSV, no ToS friction (unlike the `www.nseindia.com` host, `archives.nseindia.com` is not behind the same bot-check). Columns: Company Name, Old Symbol, New Symbol, Effective Date. Coverage: 01-Apr-1999 through forward-dated entries into 2026 (~1,650-1,700 rows, ~27 years). **This is the single best confirmed free source in this whole research task** — public, no-auth, long history, official primary source. Limitation: no ISIN column, so it maps old-symbol→new-symbol/name, not ISIN-to-ISIN.
2. **jugaad-data's undocumented BSE ISIN lookup** — `BSELive.get_scrip_info()` returns current ISIN for a BSE symbol/code (confirmed by reading source 2026-07-25); `symbol_to_scrip_code()`/`scrip_code_to_symbol()` give current symbol↔scrip-code mapping only — **no changelog/history**, so this only helps resolve today's ISIN, not track historical changes.
3. **`bse` (BennyThadikaran) `lookup()`** — searches by company name/symbol/ISIN/BSE code, returns current mapping only (confirmed from source 2026-07-25) — same limitation, current-state not history.
4. **NSDL/CDSL ISIN search** — `nsdl.co.in/master_search.php` and CDSL's securities search — both are free, no-login, single-record lookup tools (existence corroborated via search-index cache, direct fetch blocked by connection reset both times today) that return the *current* ISIN record for a company; no evidence found of a public ISIN change-history/merger-mapping feature on either depository's site. CDSL's Corporate Bond ISIN search (`cdslindia.com/CorporateBond/SearchISIN.aspx`, fetched successfully 2026-07-25) does offer bulk export, but only for the corporate-bond ISIN subset, not equities.
5. **Kaggle "Indian Stocks Listed On NSE and BSE With ISIN No."** — `https://www.kaggle.com/datasets/luficergfree/indian-stocks-listed-on-nse-and-bse-with-isin-no` (fetched 2026-07-25). MIT-licensed, last updated 2024-07-23. Current-snapshot SYMBOL/NAME/ISIN/Industry listing — useful as a base map, not a history.
6. **MCA company master data (via data.gov.in / MCA21 v3 portal)** — free CIN-level lookup (single-record, CAPTCHA-gated) confirmed to exist via secondary sources (direct mca.gov.in fetch returned 403 today); shows company status changes (active/merged/dissolved/struck-off) which is the closest free proxy for *corporate mergers* (as opposed to ISIN changes specifically), but does not carry ISIN at all. `data.gov.in`'s "Company Master Data" catalog (existence corroborated via a gimi9.com mirror and search index; direct fetch returned 403 today) is reportedly CIN/name/status/address only, partitioned by the 22 Registrars of Companies, licensed under India's GODL if the platform's standard policy applies (not independently re-confirmed today for this specific dataset page) — again, no ISIN field, so it complements but does not replace an ISIN-change table.

**Verdict for (b):** There is no free source that gives a clean **ISIN-to-ISIN** change/merger history. What exists and is genuinely usable for free: NSE's `symbolchange.csv` (name/symbol history, no ISIN, but excellent depth and total legitimacy as a direct exchange CSV) + MCA/data.gov.in company-status data (merger/dissolution flag by CIN, no ISIN) + NSDL/CDSL/BSE current-ISIN lookups to resolve today's mapping. Reconstructing full ISIN lineage for renamed/merged companies from free sources requires manually joining these three by company name/PAN-equivalent — this is a real gap, not just an inconvenience.

## (c) Delisted-securities master

1. **BSE compulsorily-delisted companies PDF** — `https://www.bseindia.com/downloads1/comp_delisted_cos_db.pdf` — **directly fetched and confirmed 2026-07-25**. Columns: Company Name, Lot Size, ISIN (often blank/"Not Available"), Face Value, Physical/Demat flag, Date of Delisting at BSE. The reviewed portion (194 rows) covers Aug-Dec 2016; the full 821.8KB PDF likely has more rows but was not exhaustively paged. Free, official, primary source, but PDF-only (not machine-friendly) and the dated snapshot's currency/update cadence is unconfirmed.
2. **BSE `ListofScripData/w` API with `status=delisted` filter** — confirmed via two independently-maintained open-source libraries reading BSE's live JSON API: `jugaad-data`'s undocumented `BSELive.get_scrip_list(status="Delisted")` and `BennyThadikaran/BseIndiaApi`'s documented `listSecurities(status="delisted")` (both read from source 2026-07-25). This is the most structured, queryable, machine-readable free delisted-list source found — free, no login, official BSE endpoint, wrapped by two actively-maintained openly-licensed libraries (GPL-3.0 and a public-domain "YOLO License").
3. **NSE delisting lists** — `nseindia.com/static/list/orders-of-delisting` and `.../list-of-companies-proposed-to-be-delisted` are known to exist (found in search results) but could not be fetched today (repeated timeouts from the tool environment against the `www.nseindia.com` host — same bot-check pattern as the corporate-actions API). Unverified format/depth; flagged as "exists, needs a browser-based re-check" rather than dismissed.
4. **Kaggle "Survivorship-Free Indian Equity Data (NSE/BSE)"** — `https://www.kaggle.com/datasets/financebroski/survivorship-free-indian-equity-data-nsebse` (fetched 2026-07-25). CC BY 4.0, updated 2026-06-23. Sample file `survivorship_universe.csv` lists 3,838 names traded 2010-2026 including 1,209 dead/delisted names with first/last-traded dates — a genuinely useful, properly-licensed cross-check dataset, though the uploader states the full universe (beyond the published sample) is only available by requesting it via the linked GitHub repo issue tracker, not as an open bulk download.
5. **SEBI** — publishes the *regulatory framework* (Delisting of Equity Shares Regulations 2021, amended through Sep 2024; delisting FAQ PDF dated Apr 2025) but, per this research, does **not** host a structured public dataset/list of delisted companies itself — that aggregation is left to the exchanges.
6. **Screener.in / Tickertape.in delisted-company profiles** — both tested against a known-delisted name (DHFL) and both returned **404** — neither retains a browsable historical page for delisted securities on the free tier, so they are not usable as a delisted-master source despite being decent for active-company corporate actions.
7. **Chittorgarh.com** — contrary to its reputation for delisting coverage, its current site navigation (scanned 2026-07-25, 292 links) has no delisted-companies tracker; its free trackers cover IPO/NCD/Rights/OFS/Buyback only. Its disclaimer page also explicitly prohibits redistribution/reuse of site content without written permission — flagged, not a viable source for this need today.

**Verdict for (c):** BSE is materially ahead of NSE here for free/legitimate delisted-securities data — both a static official PDF and a queryable JSON API (via open-source library wrappers) exist and were positively confirmed today. NSE's equivalent lists exist per search results but could not be independently verified in this session (bot-blocked); this is a concrete follow-up item (recommend re-attempting via an authenticated/browser-based fetch, e.g. Claude-in-Chrome, rather than stateless WebFetch). The Kaggle survivorship-free sample is a good properly-licensed secondary cross-check for NSE-side delisted names in the interim.

## Cross-cutting notes

- **Bot-blocking as a finding, not an assumption**: `www.nseindia.com`, `bseindia.com`'s dynamic pages, `sebi.gov.in`, `data.gov.in`, `mca.gov.in`, `nsdl.co.in`, and `ww1.cdslindia.com` all blocked or timed-out stateless fetch attempts today (2026-07-25) from this tool environment. This is consistent with known Cloudflare/WAF bot-protection on these sites, not a statement that the data doesn't exist or isn't accessible via a real browser session (which is exactly what `nselib`/`nsepython`/`bse` do — they spoof headers and carry a session/cookie). Anything above marked "could not fetch directly" should be re-verified with a session-carrying tool (Playwright/Selenium/Claude-in-Chrome) before being treated as confirmed-absent.
- **`archives.nseindia.com` is the exception** — it serves plain static files (like `symbolchange.csv`) with no bot-check, unlike `www.nseindia.com`'s API/dynamic paths. Worth checking for other archive CSVs (bhavcopy, indices) using the same host pattern.
- **License hygiene matters**: several GitHub/Kaggle items found (`rkTrader/corpActions`, the Techsalerator Kaggle teaser) have no real license or are marketing samples — usable for cross-checking only, not as a dependency, consistent with treating "no license" as "no reuse right" even though nothing here is being excluded for licensing per the project's no-license-filtering policy — the flag is about legal reuse, not a preference filter.
- **GODL claim on data.gov.in is unconfirmed today** — the platform's standard license is understood to be India's Government Open Data License, but the specific Company Master Data catalog page returned HTTP 403 on every fetch attempt today, so this specific claim rides on secondary sources (a gimi9.com mirror, search-index snippets) and should be re-verified.

## Overall verdict: how complete is a free corporate-actions/ISIN/delisting history?

**Partially complete, with real gaps, not a solved problem.**
- Corporate actions (a): achievable at "raw filings feed, needs type-parsing, unverified depth beyond a few years" quality using NSE+BSE's own free APIs via open-source library wrappers — good enough to bootstrap, not a clean typed 20-year table out of the box.
- ISIN/symbol/merger history (b): the weakest of the three. Free sources give current-state ISIN lookups and name/symbol history (NSE's `symbolchange.csv` is genuinely excellent for the symbol/name side) but nothing free stitches together a proper ISIN-to-ISIN change/merger ledger — this would need to be built by joining NSE symbol-change history + MCA/data.gov.in company-status changes + current ISIN lookups, by hand/heuristically, and will have real gaps.
- Delisted-securities master (c): BSE-side is genuinely solid free (PDF + queryable API, both confirmed). NSE-side exists per search but is unverified today due to bot-blocking, and should be re-checked with a browser-session tool. The Kaggle survivorship-free dataset is a good, properly-licensed supplementary cross-check with 1,209 delisted names and dates.

**Bottom line**: a workable free stack exists for bootstrapping all three datasets, built primarily on NSE's `symbolchange.csv` (confirmed), BSE's delisted PDF + API (confirmed), and NSE/BSE's corporate-action query APIs via `nselib`/`nsepython`/`bse` (existence and licensing confirmed from source, historical depth unverified) — but it will require real ETL/reconciliation work and has a genuine, currently-unclosed gap on ISIN-level change history. No paid product was needed to reach this point, and nothing recommended here required credential sharing, paywall bypass, or ToS-violating scraping — flagged ToS-restriction text is reported for a human decision, not silently worked around.
