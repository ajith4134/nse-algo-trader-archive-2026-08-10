# NSE Algo Trader

Autonomous intraday trading bot for Indian NSE markets (cash equity +
options). No overnight positions.

See `CLAUDE.md` for the binding project rules (build process, regulatory
constraints, naming conventions). See `docs/flowcharts/` for the
cumulative, layer-by-layer data-flow notes — start with
`docs/flowcharts/00_project_overview.md`.
